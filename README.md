# IvoryPool

Landing page responsive d’Ivoire Pool réalisée intégralement avec React, TypeScript et Vite.

## Fonctionnalités

- intégration des cinq maquettes dans leur ordre vertical ;
- responsive desktop, tablette et mobile ;
- animations d’entrée, de scroll et de survol ;
- menu mobile, FAQ interactive et galerie de projets ;
- trois visuels générés et numérotés dans `public/`.

## Installation

```bash
npm install
npm run dev
```

Pour générer la version de production :

```bash
npm run build
```
